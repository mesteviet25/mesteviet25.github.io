I have three projects whose headline finding is that a promising method did not do the thing it was
supposed to do.

That is not a bad run. That is what the work looks like when you report what happened rather than
what you set out to find.

## Nulls are expensive to produce and free to ignore

A real negative is not the absence of a result. It takes the same setup, the same pipeline, the same
weeks of debugging as a positive — and then produces something with no natural audience.

Which is why the standard move is to keep looking. Different outcome variable. Different subgroup.
Different window. Somewhere in that space is a version that clears the bar, and having found it you
write it up as though it were the first thing you tried.

Nobody experiences this as dishonest. It feels like persistence.

## What a documented negative needs to be worth reading

Not just "it did not work." That is unfalsifiable and unhelpful. It needs:

- **The reliability ceiling.** If the measurement only agrees with itself moderately, no relationship
  involving it could have been strong. Quote the ceiling next to the null or the reader cannot tell
  a real absence from a doomed design.
- **A positive control.** Point the same pipeline at something known to be there. If it fails that
  too, you have a broken method, not a finding. This is the single thing that separates a useful null
  from a shrug.
- **What you did not try.** The honest boundary. "This does not work with this outcome variable and
  this population; I did not test these other three, and here is why they might behave differently."
- **Enough detail to rebuild it.** A null is only useful if someone can check it.

## The selfish argument

Set aside the community-good version. In six months you will have this idea again.

You will not remember that you already tried it. You will remember it as promising, because that is
how it felt when you started, and the memory of the disappointment fades faster than the memory of
the appeal. Then you will spend the weeks again.

The write-up is a message to a person with your exact interests and none of your recent memory.
Address it accordingly.
